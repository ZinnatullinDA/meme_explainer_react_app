# Meme Explainer

## Описание проекта

Meme Explainer - web-приложение для просмотра мемов, добавления их в избранное, создания коллекций, заметок и объяснений. Приложение получает мемы из внешних API, показывает карточки и страницы деталей, а пользовательские данные сохраняет через локальный backend.

Основная идея проекта - объяснить старшему поколению трендовые интернет-мемы простым и понятным языком. Пользователь может открыть мем, запросить объяснение и получить краткое описание: что означает мем, в чем его шутка и в каких ситуациях его обычно используют.

В приложении также есть вкладка "Сленг". В ней можно ввести интернет-сленг или мемную фразу, а GigaChat сгенерирует понятное объяснение и карточку с изображением. Такие карточки сохраняются в локальном backend, отображаются на странице сленга и добавляются в общий список мемов.

Для генерации объяснений реализована интеграция с GigaChat. Backend отправляет запрос к ИИ с названием выбранного мема, получает ответ и сохраняет объяснение в локальном хранилище. При необходимости пользователь может отредактировать сгенерированный текст вручную.

## Как запустить проект

Проект состоит из двух частей: frontend и backend. Для удобства их можно запустить одной командой из корня проекта.

### Быстрый запуск из корня проекта

```bash
npm i
npm run start
```

Команда `npm run start` одновременно запускает backend и frontend. После запуска frontend будет доступен по адресу, который выведет Vite, обычно `http://localhost:5173`, а backend - на `http://localhost:3002`.

Для генерации объяснений через GigaChat в `backend/.env` должен быть указан ключ `GIGACHAT_AUTH_KEY`.

### Запуск по отдельности

Если нужно запустить части проекта вручную, используйте отдельные терминалы.

### Frontend

```bash
cd frontend
npm i
npm run dev
```

После запуска frontend будет доступен по адресу, который выведет Vite, обычно `http://localhost:5173`.

### Backend

```bash
cd backend
npm i
npm run dev
```

Backend запускается на `http://localhost:3002`. Frontend проксирует запросы `/api` на backend через настройки Vite.

### Полезные команды из корня проекта

```bash
npm run lint
npm run typecheck
npm run build
```

## Архитектура проекта

```text
meme_explainer_react_app/
├── frontend/                  # Клиентская часть приложения
│   ├── public/                # Статические файлы и иконки
│   ├── src/
│   │   ├── app/               # Инициализация приложения, роутер, store, провайдеры
│   │   ├── entities/          # Бизнес-сущности: мемы, избранное, коллекции, заметки, объяснения
│   │   ├── features/          # Пользовательские действия и сценарии
│   │   ├── pages/             # Страницы приложения
│   │   ├── shared/            # Общие API-клиенты, конфигурация, хуки и UI-компоненты
│   │   ├── widgets/           # Крупные UI-блоки: лента мемов, детали мема
│   │   ├── index.css          # Глобальные стили
│   │   └── main.tsx           # Точка входа React-приложения
│   ├── vite.config.ts         # Конфигурация Vite и proxy для backend
│   └── package.json           # Скрипты и зависимости frontend
│
├── backend/                   # Серверная часть приложения
│   ├── data/
│   │   └── db.json            # Локальное JSON-хранилище пользовательских данных
│   ├── src/
│   │   └── server.js          # Express-сервер и REST API
│   ├── .env                   # Переменные окружения backend
│   └── package.json           # Скрипты и зависимости backend
│
├── .gitignore
└── README.md
```

Frontend построен по модульному подходу, близкому к Feature-Sliced Design: общая инфраструктура находится в `shared`, доменные модели - в `entities`, пользовательские сценарии - в `features`, страницы - в `pages`, а крупные композиционные блоки - в `widgets`.

Backend представляет собой Express API с простым JSON-хранилищем. Сервер читает и обновляет данные в `backend/data/db.json`, а также содержит интеграцию с GigaChat для генерации объяснений мемов.

## Используемые технологии

- React - библиотека для построения пользовательского интерфейса.
- TypeScript - типизация frontend-кода.
- Vite - сборщик и dev-сервер frontend.
- Redux Toolkit - управление состоянием приложения.
- React Redux - связка React с Redux store.
- TanStack Router - клиентская маршрутизация.
- Express - backend-сервер и REST API.
- CORS - настройка доступа к backend API.
- Node.js - среда выполнения backend.
- GigaChat API - генерация объяснений мемов.
- Imgflip API и Meme API - получение мемов из внешних источников.
- ESLint - проверка качества кода frontend.
- Prettier - единое форматирование кода и документации.
- commitlint - проверка сообщений коммитов по Conventional Commits.

## Реализованные модули

### Frontend

- Главная страница с лентой мемов.
- Страница деталей выбранного мема.
- Вкладка "Сленг" для объяснения интернет-сленга и мемных фраз.
- Страница избранных мемов.
- Страница коллекций.
- Фильтрация и поиск мемов.
- Пагинация списка мемов.
- Добавление и удаление мемов из избранного.
- Создание коллекций и добавление мемов в коллекции.
- Создание, редактирование и удаление заметок к мемам.
- Создание, редактирование, удаление и генерация объяснений мемов.
- Генерация сленговых карточек через GigaChat и отображение их в отдельной вкладке.
- Получение данных из backend API и внешних API мемов.
- Хранение состояния через Redux Toolkit.
- Клиентская маршрутизация через TanStack Router.

### Backend

- Проверка состояния сервера: `GET /api/health`.
- Работа с избранным:
  - `GET /api/favorites`
  - `POST /api/favorites`
  - `DELETE /api/favorites/:memeId`
- Работа с объяснениями:
  - `GET /api/explanations`
  - `POST /api/explanations`
  - `POST /api/explanations/generate`
  - `PATCH /api/explanations/:id`
  - `DELETE /api/explanations/:id`
- Работа с заметками:
  - `GET /api/notes`
  - `POST /api/notes`
  - `PATCH /api/notes/:id`
  - `DELETE /api/notes/:id`
- Работа с коллекциями:
  - `GET /api/collections`
  - `POST /api/collections`
  - `PATCH /api/collections/:id/toggle-meme`
- Работа со сленговыми карточками:
  - `GET /api/slang/memes`
  - `POST /api/slang/explain`
- Локальное сохранение данных в JSON-файл.
- Генерация объяснений мемов через GigaChat API.
